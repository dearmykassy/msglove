# 마사지러브 사이트 아키텍처

## 페이지 계층

```text
홈 (/)
├── 지역 라운지 (/areas)
│   └── 11개 운영 권역 (/areas/{root})
│       └── 시·구 허브 (/areas/{root}/{hub...})
│           └── 대표 지역 (/areas/{root}/{hub...}/{region})
├── 이용 방식 (/guide)
├── 코스 라인업 (/pricing)
├── 러브 셀렉트 (/love-select)
├── 이브닝 노트 (/evening-note)
└── 알림 (/notice)
```

고정 페이지는 7개, 활성 지역 페이지는 정확히 1,291개로 고객용 페이지
총수는 1,298개다. `robots.txt`, `sitemap.xml`, 404 같은 기술 산출물은
이 수에 포함하지 않는다.

## 내비게이션

데스크톱 헤더는 `지역 라운지 → 이용 방식 → 코스 라인업 → 러브 셀렉트 →
이브닝 노트 → 알림` 순서다. 전화번호는 우측 독립 CTA다. 모바일은 동일
링크를 `details` 메뉴의 2열 목록으로 제공해 로고와 메뉴가 충돌하지 않는다.

## URL과 내부 링크

| 유형 | URL | 진입 링크 | 주요 다음 링크 |
|---|---|---|---|
| 홈 | `/` | 로고 | 11개 권역, 가격, 에디토리얼 |
| 권역 목록 | `/areas` | 헤더·홈 | 11개 root |
| 지역 root/hub | `/areas/{segments}` | 부모·디렉터리 | 하위 지역, 가격, 전화 |
| 대표 지역 | `/areas/{segments}` | 부모 디렉터리 | 가격, 이용 방식, 에디토리얼 |
| 이용 방식 | `/guide` | 헤더·푸터 | 지역, 전화 |
| 가격 | `/pricing` | 헤더·지역 | 전화, 지역 |
| 러브 셀렉트 | `/love-select` | 헤더·지역 | 향후 지역 글 |
| 이브닝 노트 | `/evening-note` | 헤더·지역 | 향후 도시 노트 |

모든 지역 페이지에는 홈부터 현재 노드까지 breadcrumb가 있고, root와 hub는
직접 하위 지역을 즉시 노출한다. 대표 지역도 가격·이용 방식·두 에디토리얼
허브로 연결돼 고아 페이지가 생기지 않는다.

## 색인 정책

도메인과 공개 승인이 없으면 전 페이지 `noindex, nofollow` 및 robots 전체
차단이다. 실제 도메인과 `MASSAGE_LOVE_PUBLIC_LAUNCH_APPROVED=true`가 함께
설정돼야 index/follow와 sitemap 공개 정책이 열린다.
