# 공개 출시 게이트

현재 로컬 프로토타입과 정적 빌드는 허용하지만 공개 출시는 아래 항목이
모두 완료될 때까지 차단한다.

- [ ] `마사지러브` 상호 사용과 운영 주체 고지 확인
- [ ] 실제 도메인 확정 및 제3자 상표·유사업종 충돌 검토
- [ ] `NEXT_PUBLIC_SITE_ORIGIN`을 실도메인 HTTPS로 설정
- [ ] 323개 지역 이미지와 홈 전용 1개 이미지 생성·사람 검수
- [ ] 홈 포함 324개 전부 마사지러브 전용 refine·3종 반응형·SHA·pHash·
  상·하류 사람 검수·팔레트·헤더 결속 완료(원본 직접 공개/기존 refiner 면제 금지)
- [ ] 공유 full-image 감사 PASS 및 원자적 공개 승격 receipt 확인
- [ ] 전체 지역 corpus의 교차 플랫폼 중복 감사 PASS — 현재
  `PENDING_FINAL_INTEGRATION`; Rang Therapy·Mixed Love Massage의 최종
  `FAST_CANDIDATE` actual/corpus 해시가 고정된 뒤 다시 결속한다.
- [x] 전화·가격 14항목·24시간·현장 후불·카드 결제의 코드/테스트 일치
- [ ] 공개 직전 운영자가 전화·가격·결제 사실을 최종 재확인

  대표 9건 기능 QA PASS. 이는 in-app browser 또는 사람 시각 검수 주장이 아니다.
