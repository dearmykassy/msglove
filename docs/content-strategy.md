# 마사지러브 콘텐츠 전략

## 콘텐츠 기둥

1. **지역 상담 문서** — 주소·희망 시간·코스·결제 방식을 판단하는 1,291개
   고의도 페이지. 지역 계층과 포함 행정명은 검증된 원장만 사용한다.
2. **러브 셀렉트** — 한 끼, 카페, 야간 공간을 예산·이동·머무는 시간으로
   고르는 로컬 큐레이션. 실제 장소 정보가 확인된 글만 발행한다.
3. **이브닝 노트** — 약속 전후 시간, 늦은 이동, 날씨 변화처럼 저녁 계획을
   덜 복잡하게 만드는 도시 생활 가이드.

## 지역 문서 모델

각 문서는 `히어로 → 지역 좌표 → 상담 데스크 → 코스 레저 → 현장 후불
원칙 → 방문 흐름 → 빠른 답변 → 에디토리얼` 순서다. 7개 장문 문단은
전체 행정 맥락, 하위 지역 수, 포함 행정명, 결정적 문장 변주를 조합한다.
지역명만 치환한 한 문단 복제는 허용하지 않는다.

## 검색 키워드 소유권

- `{지역}마사지러브`
- `{지역}24시방문마사지`
- `{지역}현장후불마사지`
- `{지역}카드결제출장마사지`
- `{지역}출장아로마코스`
- `{지역}출장타이코스`

동명이 다른 행정 맥락에 존재하면 전체 지역 맥락을 결합해 keyword string의
충돌을 막는다. generic head term을 본문에 반복하거나 숨은 키워드를 만들지
않는다. 검색어는 고객이 실제로 확인할 수 있는 정보와 함께 사용한다.

## 발행 순서

1. 지역 페이지 corpus·메타·내부 링크 전수 검증
2. 이미지 323장 원본 QA와 정제·팔레트 배정
3. 실제 도메인·브랜드·법적 고지 확인
4. root/hub 중심의 1차 색인 후 대표 지역을 단계적으로 모니터링
5. 러브 셀렉트와 이브닝 노트는 확인된 개별 글부터 발행
